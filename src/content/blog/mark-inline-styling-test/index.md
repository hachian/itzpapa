# マークハイライト＋インラインスタイル併用テスト

このページでは、マークハイライト記法（`==text==`）と他のインラインスタイリングの併用をテストします。

---

## 1. 基本確認（単独使用）

まず単独での動作を確認します。

### 1.1 単独のマークハイライト
- 結果: ==これはハイライトされるべき==
- 期待: 黄色背景でハイライト表示

### 1.2 単独のstrong
- 結果: **これは太字になるべき**
- 期待: 太字表示

### 1.3 単独のemphasis
- 結果: *これは斜体になるべき*
- 期待: 斜体表示

### 1.4 単独のinline code
- 結果: `これはコードになるべき`
- 期待: モノスペースフォント、背景色付き

---

## 2. strong + mark の併用（バグ対象）

### 2.1 strongの中にmark: `**==text==**`
- 結果: **==これは太字＋ハイライト==**
- 期待: 太字かつ黄色背景

### 2.2 markの中にstrong: `==**text**==`
- 結果: ==**これはハイライト＋太字**==
- 期待: 黄色背景かつ太字

### 2.3 strongの中に複数のmark
- 結果: **==ハイライト1==と==ハイライト2==**
- 期待: 「ハイライト1」と「ハイライト2」がそれぞれハイライト、全体が太字

---

## 3. emphasis + mark の併用（バグ対象）

### 3.1 emphasisの中にmark: `*==text==*`
- 結果: *==これは斜体＋ハイライト==*
- 期待: 斜体かつ黄色背景

### 3.2 markの中にemphasis: `==*text*==`
- 結果: ==*これはハイライト＋斜体*==
- 期待: 黄色背景かつ斜体

### 3.3 emphasisの中に複数のmark
- 結果: *==ハイライト1==と==ハイライト2==*
- 期待: 「ハイライト1」と「ハイライト2」がそれぞれハイライト、全体が斜体

---

## 4. inline code + mark の併用

### 4.1 markの中にcode: `` ==`code`== ``
- 結果: ==`console.log('hello')`==
- 期待: コードブロックがハイライト背景で表示

### 4.2 code内の==はリテラル: `` `==text==` ``
- 結果: `==これはハイライトされない==`
- 期待: `==text==`がそのまま表示（ハイライトなし）

### 4.3 strong + mark + code: `` **==`code`==** ``
- 結果: **==`重要なコード`==**
- 期待: 太字、ハイライト背景、コードスタイル

### 4.4 emphasis + mark + code: `` *==`code`==* ``
- 結果: *==`斜体コード`==*
- 期待: 斜体、ハイライト背景、コードスタイル

---

## 5. 複合スタイル（3重以上の入れ子）

### 5.1 strong + emphasis + mark: `***==text==***`
- 結果: ***==太字＋斜体＋ハイライト==***
- 期待: 太字、斜体、ハイライトすべて適用

### 5.2 別の記法: `**_==text==_**`
- 結果: **_==太字＋斜体＋ハイライト（別記法）==_**
- 期待: 太字、斜体、ハイライトすべて適用

### 5.3 4重の組み合わせ
- 結果: ***==`最強の強調`==***
- 期待: 太字、斜体、ハイライト、コードすべて適用

---

## 6. エッジケース

### 6.1 空のstrong内のmark
- 結果: ****
- 期待: 空のstrong（何も表示されない）

### 6.2 隣接するスタイル
- 結果: **太字**==ハイライト==*斜体*
- 期待: それぞれ独立して適用

### 6.3 途中で切り替わるスタイル
- 結果: **太字開始==太字＋ハイライト==太字終了**
- 期待: 全体が太字、中央部分のみハイライト

### 6.4 ネストが深すぎる場合
- 結果: **_==***深いネスト***==_**
- 期待: 適切にフォールバックまたは処理

---

## 7. 実用的なユースケース

### 7.1 重要なコード変数
設定で**==`DEBUG=true`==**を指定してください。

### 7.2 警告テキスト
*==注意: この操作は元に戻せません==*

### 7.3 強調された引用
> **==重要な引用文==**をここに記載します。

### 7.4 リスト内での使用
1. **==ステップ1==**: 設定ファイルを開く
2. *==ステップ2==*: 値を変更
3. ==`ステップ3`==: 保存して再起動

### 7.5 テーブル内での使用

| 項目 | 説明 | 重要度 |
|------|------|--------|
| **==設定A==** | 必須の設定項目 | 高 |
| *==設定B==* | オプション設定 | 中 |
| ==`CONFIG_C`== | 環境変数 | 低 |
