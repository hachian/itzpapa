# Implementation Plan

## Tasks

- [x] 1. 検索機能の国際化対応
- [x] 1.1 検索UI用の翻訳キーを追加
  - 検索ページタイトル、プレースホルダー、ボタンラベルの翻訳を定義
  - 検索結果なしメッセージ、件数表示、入力促進メッセージの翻訳を定義
  - パンくずナビゲーション用の翻訳キーを追加
  - 日本語・英語両方の翻訳テキストを設定
  - _Requirements: 1.3, 6.1_

- [x] 2. 検索インデックスの生成
- [x] 2.1 (P) Markdown本文からプレーンテキストを抽出する機能を実装
  - Markdown記法（見出し、リンク、コードブロック、画像等）を除去
  - Obsidian固有記法（WikiLink、Callout、ハイライト）も除去対象
  - 改行・空白を正規化して検索しやすいテキストに変換
  - _Requirements: 2.1_

- [x] 2.2 ビルド時に検索インデックスJSONを生成
  - 全ブログ記事を取得し、公開済み記事のみを対象とする
  - 各記事のslug、タイトル、プレーンテキスト化した本文を含むJSONを生成
  - ビルドプロセスに組み込み、自動的にインデックスを更新
  - _Requirements: 2.1, 2.4_

- [x] 3. クライアントサイド検索エンジン
- [x] 3.1 (P) 検索インデックスの読み込みとキャッシュ機能を実装
  - 初回検索時にインデックスJSONをfetch
  - 取得したデータをメモリにキャッシュして再利用
  - fetch失敗時のエラーハンドリングを実装
  - _Requirements: 2.1_

- [x] 3.2 部分一致検索ロジックを実装
  - 大文字小文字を区別しない部分一致検索を実行
  - 空クエリの場合は即座に空結果を返す
  - 1記事内の複数ヒットを個別の結果として返却
  - _Requirements: 2.1, 2.2, 2.3, 3.3_

- [x] 3.3 ヒット箇所のコンテキスト抽出機能を実装
  - ヒット箇所の前後50-100文字程度のスニペットを抽出
  - コンテキスト内でのハイライト位置情報を計算
  - 記事タイトルとslugを結果に含める
  - _Requirements: 3.1, 3.2, 3.4_

- [x] 4. 検索ページの構築
- [x] 4.1 検索ページの基本レイアウトを作成
  - `/search/` パスでアクセス可能なページを作成
  - ヘッダー、フッター、パンくずナビゲーションを含む標準レイアウト
  - レスポンシブデザインでモバイル・デスクトップ両対応
  - _Requirements: 1.1, 1.3, 1.4_

- [x] 4.2 検索フォームを実装
  - テキスト入力フィールドと検索ボタンを配置
  - URLクエリパラメータから検索語を読み取り初期表示
  - 入力時のdebounce処理で過度な検索実行を防止
  - XSS対策としてクエリをエスケープ
  - _Requirements: 1.2, 2.3_

- [x] 4.3 検索結果の表示機能を実装
  - 検索エンジンを呼び出して結果を取得・表示
  - 各結果にタイトルとコンテキストスニペットを表示
  - コンテキスト内の検索語句をハイライト表示
  - 結果クリックで記事ページへ遷移（ハイライトパラメータ付き）
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 4.1_

- [x] 4.4 検索結果なし・空クエリ時の表示を実装
  - 検索結果が0件の場合に適切なメッセージを表示
  - 空クエリ時に入力を促すメッセージを表示
  - 再検索できる状態を維持
  - _Requirements: 2.3, 6.1, 6.2_

- [x] 5. 検索結果のページネーション
- [x] 5.1 (P) 検索結果のページ分割ロジックを実装
  - 設定された件数で結果を分割
  - 現在のページ番号と総ページ数を計算
  - URLクエリパラメータでページ状態を管理
  - ページ移動時も検索クエリを維持
  - _Requirements: 5.1, 5.3, 5.5_

- [x] 5.2 ページネーションUIを統合
  - 既存のPaginationコンポーネントを活用
  - 検索クエリを含むURLを生成
  - 前後ページへのナビゲーションを提供
  - _Requirements: 5.2, 5.4_

- [x] 6. 記事ページでのハイライト・スクロール
- [x] 6.1 (P) URLパラメータからハイライト対象を読み取る機能を実装
  - `?highlight=検索語` パラメータを解析
  - 空のパラメータは無視
  - _Requirements: 4.1_

- [x] 6.2 記事本文内の該当テキストをハイライトしスクロール
  - 本文DOM内で検索語句を探索
  - 最初のヒット箇所に視覚的なハイライトを適用
  - 該当箇所まで自動スクロール
  - _Requirements: 4.2, 4.3_

- [x] 7. 統合テストと最終確認
- [x] 7.1 検索機能のE2Eテストを実施
  - 検索フォーム入力から結果表示までのフロー確認
  - 結果クリックから記事ページでのハイライト・スクロール確認
  - ページネーション動作の確認
  - 0件結果時のメッセージ表示確認
  - _Requirements: 1.1, 1.2, 2.1, 3.1, 4.1, 4.2, 5.1, 6.1_

- [x] 7.2 レスポンシブデザインの確認
  - モバイル・デスクトップ両方での表示確認
  - 検索フォーム、結果一覧、ページネーションのレイアウト確認
  - _Requirements: 1.4_
